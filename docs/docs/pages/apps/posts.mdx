# Posts

![demo of posts](https://assets.andromeda.build/posts-demo.png)

A self-hosted blog CMS built in Go.

- Single Go binary with embedded assets
- Password authentication with session cookies
- Create, edit, publish, and delete blog posts with markdown
- Static pages with custom navigation links
- File uploads with admin management
- Custom CSS support from the admin panel
- RSS feed at `/feed.xml`
- JSON API for reading and creating posts
- Dark themed UI with Commit Mono font
- SQLite for persistent storage

## Configure

### Environment Variables

| Variable | Description | Default |
|---|---|---|
| `POSTS_PASSWORD` | Password for admin login | `changeme` |
| `POSTS_API_KEY` | API key for creating posts via `POST /api/posts` | _(unset)_ |
| `POSTS_DB_PATH` | SQLite database file path | `posts.sqlite` |
| `UPLOADS_DIR` | Directory for uploaded files (used when R2 unset) | `uploads` |
| `SITE_URL` | Public URL for RSS feed and links | `http://localhost:3000` |
| `HOST` | Server bind address | `127.0.0.1` |
| `PORT` | Server port | `3000` |
| `COOKIE_SECURE` | Enable HTTPS-only cookies | `false` |
| `R2_BUCKET` | Cloudflare R2 bucket name (enables R2 storage) | _(unset)_ |
| `R2_ACCOUNT_ID` | Cloudflare account ID | _(unset)_ |
| `R2_ACCESS_KEY_ID` | R2 access key ID | _(unset)_ |
| `R2_SECRET_ACCESS_KEY` | R2 secret access key | _(unset)_ |
| `R2_PUBLIC_URL` | Public URL prefix for uploaded files | _(unset)_ |

Upload storage falls back to local filesystem (`UPLOADS_DIR`) when `R2_BUCKET` is empty. Set all five `R2_*` variables to switch uploads to Cloudflare R2.

If `POSTS_API_KEY` is not set, `POST /api/posts` returns `403`. The read-only `GET` endpoints are always public.

## Deploy

### Railway

The easiest way to deploy Posts is with the one-click Railway template. See the [Deploying with Railway](/deploy-railway) guide for a walkthrough of the process. Posts requires `POSTS_PASSWORD` and `SITE_URL` to be set during the configure step.

[![Deploy on Railway](https://railway.com/button.svg)](https://railway.com/deploy/andromeda-posts)

### Docker

```bash
cd apps/posts
cp .env.example .env
# Edit .env with your password
docker compose up -d
```

This will start Posts on port `3000` with a persistent volume for the SQLite database and uploads.

### Binary

Install with Homebrew:

```bash
brew install stevedylandev/tap/posts
```

Or grab a prebuilt binary from the [releases page](https://github.com/stevedylandev/andromeda/releases?q=posts&expanded=true).

You can also build from source:

```bash
cd apps/posts && go build .
```

The resulting binary is self-contained with all assets embedded. Copy it to your server with a configured `.env` file and run it directly.

## Use

Log in at `/login` with your configured password to access the admin panel. From there you can manage blog posts, static pages, file uploads, and site settings including custom CSS. Your blog's RSS feed is available at `/feed.xml`.

### API Endpoints

| Method | Path | Description |
|---|---|---|
| `GET` | `/api/posts?limit=30` | List published posts |
| `GET` | `/api/posts/{slug}` | Get a published post by slug |
| `POST` | `/api/posts` | Create a post |

`POST /api/posts` requires an `x-api-key` header matching `POSTS_API_KEY`. The JSON body accepts:

| Field | Description | Default |
|---|---|---|
| `content` | Markdown content (required) | — |
| `title` | Post title | _(none)_ |
| `slug` | URL slug | Derived from title, or a random ID |
| `status` | `draft` or `published` | `draft` |
| `published_date` | Publish date (RFC3339 or `YYYY-MM-DD`) | Now |
| `lang` | Language code | `en` |
| `tags` | Comma-separated tags | _(none)_ |
| `alias` | Alternate path that redirects to the post | _(none)_ |
| `canonical_url` | Canonical URL | _(none)_ |
| `meta_description` | Meta description | _(none)_ |
| `meta_image` | Meta image URL | _(none)_ |
| `weather` | Weather string | Fetched for the default location |

Returns `201` with the created post, `400` for invalid input, or `409` if the slug already exists.

```bash
curl -X POST https://your-posts-instance.com/api/posts \
  -H "x-api-key: $POSTS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"title": "Hello World", "content": "My first post via the API", "status": "published"}'
```
